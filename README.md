# flaron ooc
this is a slack bot for the Hack Club workspace that allows you to use the flaron API to find out which private channel/dm a message was forwarded from (slack doesnt show it by default, some client mods do tho).

## how to use

1. click "more actions" on a message with a forward
![image](https://user-cdn.hackclub-assets.com/01a1ce7f-c3cd-7697-9ddb-b025b0a36e41/screenshot_2026-11-12_at_12.37.33___pm.png)
2. click "connect to apps" -> "more message shortcuts" (or "get forward/ooc channel" if it is there)
![image](https://user-cdn.hackclub-assets.com/01a1ce7f-c26f-7c87-8c1c-0d99c1020f83/screenshot_2026-11-12_at_12.38.10___pm.png)
3. (if you clicked "more message shortcuts") type "flaron ooc" in the search bar and click "Get forward/OOC channel"
![image](https://user-cdn.hackclub-assets.com/01a1ce7f-c0f3-77e3-b016-996466dea27e/screenshot_2026-11-12_at_12.38.53___pm.png)
4. a popup should open up! if it says a channel name that is the channel name, sometimes flaron cant find the name in which case it says "not found". if its a dm it will say "dm id".
![image](https://user-cdn.hackclub-assets.com/01a1ce7f-be54-79e7-9c52-f0e8e9a5add2/screenshot_2026-11-12_at_12.41.34___pm.png)
